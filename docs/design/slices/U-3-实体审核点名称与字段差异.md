# U-3 · 实体审核点名称与字段差异

实现：Codex；审核：Claude；Refs #544。真实模型、问答、评委、线上读取/写入与部署均为 0。
工作目录 `.worktrees/u3`，分支 `slice/u3`，从 `origin/main` 建立。

## 1. 目标与现状

RV6c 的非 Claim 审核点只显示 slug 和“其他内容有更新”。本片只修订其**实体**点展示：名称优先、
字段前后差异可读。保留 Claim 点、非实体成员、选择/理由/批准拒绝、权限与发布语义。

`ReviewDetail.bundle_members` 已含候选 payload，`head_release_id` 指定比较版本；`useReviews`
已读取对应 Release 并检查生命周期。本片复用这些数据，不新增 API、合同、读取或缓存。

## 2. 展示规则

### 2.1 名称与身份

- 以成员 `kind=entity` 识别，不能仅凭 slug 前缀把其他成员当实体。
- 新增/更新取候选 `names` 中首个非空字符串；删除取对应快照的名称。没有名称则用该成员
  `entity_id`，再没有用原 slug。次要位置保留 slug，名称与内容均按文本转义。
- 不按产品/方法类型列特判，不根据 ID 查询其他实体或服务。

### 2.2 字段差异

- 只比较相同 slug 的实体 payload；每个变动字段一行，标出“现在/改为”与新增/删除/修改。
  新增/删除实体也展示逐字段差异，删除仍保留原“删除这一项”提示与审核操作。
- 对象递归到叶值（包括空对象与非空对象之间的变动），字段顺序按键排序；数组按完整有序值
  比较，不猜数组元素的身份。对象键顺序不构成变化。新增/删除非空对象展开到叶；新增/删除
  空对象、空数组及对象与其他类型互换保留完整值，不能把最后一个子字段删除笼统显示为父字段。
- 缺键、`null`、空字符串、`false`、`0` 各自不同。不存在显示“未设置”，实际值使用 JSON
  文本表示，避免类型转换丢失含义。未知键显示完整 JSON Pointer 字段路径，不隐藏或猜测中文名。
- 比较版本不可用/不匹配时只展示候选字段，前值标“不可读取”，不声称新增/修改/删除；原有
  重试提示与操作阻止不变。无 Active 的首批候选（明确 `head_release_id=null`）视为已知无前值。
- payload 相同但成员其他元数据更新时明确显示“实体字段无变化”，不编造字段变化。

### 2.3 展示配置与值解释

- 新增前端自有的声明式实体字段词表 JSON（带版本）。词表将 JSON Pointer 映射到翻译键，覆盖
  实体名称/别名/类型/分类/归属、`identifiers`（包括 `notice`）、`lifecycle`、`product_family`
  及其现有合同子字段。组件和差异算法不写死中文领域标签。
- 五语言企业词表补齐相同键。未知子字段显示路径，不能用父级泛称抹掉具体变化。
- 词表可为字段配置同版本 PresentationProfile 的值字典路径；首例 `identifiers.notice` →
  profile 的 `notices`。前后两侧分别在各自快照/候选合成版本用现有 `profileMemberFor` 选择
  profile；字典缺失保留原始值，存在则同时展示原始 token 与实际说明，不把解释变化当实体值变化。
- 词表为 UI 展示数据，不改变 Release 身份、合同、领域判断或审核路由；本片不新增依赖。
