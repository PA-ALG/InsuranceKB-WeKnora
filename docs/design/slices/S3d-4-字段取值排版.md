## 1. 问题

产品页（S3d-3a）把每个字段的取值原样放进一个 `pre-wrap` 文本块。真实取值大多是长文本：

- 现有 5 款编译输出共 138 个有内容的字段，79 个超过 300 字；1828"疾病定义与认定标准"有 23,334 字。
- 取值本身有结构，但被连成一段。常见形式：
  - "1. 名称：内容。2. 名称：内容"；
  - 条内再分"（1）…；（2）…""①…；②…"；
  - 疾病清单"1 恶性肿瘤——轻度：…。2 原位癌：…"。
- 每个字段都挂一个"原文依据"标签，"出处 n"一排排铺开，字段之间间隔小，主次不清。

长内容是字段规则有意要求的，例如"逐项编号，不得用'等'省略"。Agent 回答问题时也需要完整取值，所以**只改显示，不改数据**。

## 2. 目标

1. **分条**：自动识别取值中的编号结构，按层显示为列表；每条开头的"名称："加粗。规则通用，不按字段、产品或险种特判。
2. **缩略版 / 完整版**：
   - 长取值默认显示缩略版。有编号结构时只列每条的名称（目录），点一条展开这一条；没有结构时显示前 3 行。
   - "查看完整版"一次展开全部，"收起"回到缩略版。
3. **来源标注降噪**：
   - "原文依据"是绝大多数字段的来源，不再显示为标签，只留给读屏软件；页面顶部说明"未标注来源的内容均有原文依据"。
   - 其他来源照常显示标签。"模型补充"仍单独成组、单独标注（硬边界 6 不变）。
4. **层次**：
   - 字段名单独一行、加粗，"出处 n"紧凑地放在字段名右侧；
   - 取值在下方占满宽度；
   - 字段之间、分组之间留出间距。

**不在本片**：模型写的"要点"摘要。它是新生成的内容，需要编译时生成、逐句回指原文并经过审核，另立切片。

## 3. 设计

### 3.1 分条解析 `frontend/src/enterprise/valueOutline.ts`（纯函数）

```ts
export interface OutlineItem {
  marker: string          // 原文中的编号，如 "1." "（2）" "③" "4"
  lead: string            // 条目开头的"名称："（含冒号），没有则为 ''
  body: string            // 名称之后、子条目之前的文字
  children: OutlineItem[]
}
export interface ValueOutline { intro: string; items: OutlineItem[] }
export function valueOutline(value: string | string[]): ValueOutline
export function outlineText(outline: ValueOutline): string   // 按顺序拼回全部文字
```

- **编号族**（四种）：
  - 点号：`1.` `1．` `1、`（最多 3 位数，病种清单常到 120），后面不能紧跟数字，所以 `7.2` 不算；
  - 括号：`（1）` `(1)`；
  - 圈号：`①`…`⑳`；
  - 空格：数字 + 空白 + 不超过 32 字的名称 + `：`/`:`，如 `1 恶性肿瘤——轻度：`。
- **边界**：编号必须出现在开头，或紧跟（忽略空白）`。；;！!？?：:` 或换行之后。
  - 因此 `第（1）项`、`“8.轻度疾病释义”`、`编码3、6、9`、`0.09` 都不是编号。
- **连续**：一个编号族的条目必须从 1（或 ①）起、逐个加一；找不到下一个号就结束。少于 2 条不成列表。
- **选层**：在当前文字里，取第一个编号最靠前的族作为这一层（同位置按上面的顺序）。
  - 第一个编号之前的文字是 `intro`；
  - 每条到下一条编号前为止，最后一条到文末；
  - 条内文字用剩下的族递归解析，最多 3 层。
- **空白**：`intro`、`lead`、`body` 去掉首尾空白；`marker` 不含空白。
- **名称**：条目文字（去掉开头空白）在第一个 `：`/`:` 之前不超过 32 字，且不含 `。；;，,！!？?` 与换行时，这一段连同冒号是 `lead`。
- **数组取值**：每个元素是一条，没有编号，各自识别名称并递归解析；只有一个元素时按字符串处理。
- **不丢字**：`outlineText(valueOutline(v))` 去掉空白后与 `v` 去掉空白后完全相同（数组按元素顺序拼接）。

### 3.2 显示 `EnterpriseField.vue` 与新组件 `OutlineList.vue`

- **结构**：
  - 字段头 `.ek-field__head`：左侧字段名（加粗），右侧来源标签与"出处 n"按钮（按钮文字不变）；
  - 下方是取值 `.ek-field__value`。
- **长取值**：取值总字数超过 `LONG_CHARS = 240`。只有长取值才有缩略版和切换按钮。
- **有编号结构**：
  - 短取值：直接显示多层列表，全部展开，不加折叠控件。
  - 长取值的缩略版：
    - `intro` 最多显示 2 行；
    - 每条用 `<details data-item>`：`<summary>` 显示编号与名称；没有名称时 `<summary>` 显示编号与正文，收起时正文截成一行加省略号，展开后显示全文（正文在 DOM 中只出现一次）；
    - 子条目同样处理；默认全部收起。
    - 名称加正文不超过 40 字且没有子条目的短条目，整条直接显示，不折叠，以免折叠后摘要与正文重复。
  - 同一层有 6 条及以上、都没有子条目、且至少 80% 是短条目时（例如病种名称清单），这一层排成自动换行的一段，不再一条一行，以免上百个病种名占上百行；这一层不折叠。
  - 完整版：所有 `<details>` 展开。
- **没有编号结构**：短取值原样显示；长取值缩略版用 CSS 截到 3 行，完整版不截。
- **切换按钮**：只在长取值显示，`data-toggle`，`aria-expanded` 表示是否完整版；文字"查看完整版"/"收起"；缩略版且有编号结构时旁边显示"共 n 项"。
  - 切换只改显示，不重新请求，不改变已打开的出处。
- **来源标签**：
  - `SOURCE_SUPPORTED` 的 `[data-origin]` 仍在 DOM 中（文字"原文依据"），用 `.ek-sr-only` 视觉隐藏；
  - 其他来源可见。"模型补充"一组照旧（S3d-3a）。
- **页面说明**：`EnterpriseEntity.vue` 在版本号下加一行 `[data-source-note]`："未标注来源的内容均有原文依据，点"出处"可查看原文"。

### 3.3 样式 `enterprisePage.css`

- 字段不再用"字段名 | 取值"两列；字段间距 14px，分组标题 17px。
- 取值行高 1.75。
- 列表缩进逐层增加；`summary` 可点、有焦点样式；名称加粗。
- 没有编号结构的长取值在缩略版用 `-webkit-line-clamp: 3`。
