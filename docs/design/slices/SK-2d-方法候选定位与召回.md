## 1. 目标、选择与不变

复制件与 RAW 的排版/切块方式可能不同。本片在方法候选层去除显示格式差异，允许可证明的连续边界重叠，
同时拒绝重复位置和零散短语。候选只携方法名称、复制映射和 RAW `segments.v1` 块 ID，不携正文。

选择确定性规范化 + 唯一连续位置；不采用编辑距离/相似度（可能忽略数字和否定），不把复制块拼成整文
（会抹掉引用边界）。严格双向包含仍优先；部分重叠只补切块边界，不把一小段相同文字当全文相等。

不改：复制下载/清单/映射、原生 Wiki 输入模型、平台/合同、材料用途登记、解析/分段、方法取值、卡片/协议/
编译身份、Claim/Evidence/引文回验、审核/发布/准入。新版候选可扩大原方法的来源块，现有 SK-2 准入和取值
请求身份按既有逻辑处理；不自动重新取值、提交或发布。旧候选文件仍可读，重生成由操作方另行执行。

## 2. 文本与长度

仅定位用临时副本，原文不修改：

1. NFKC；删除 Unicode 空白；统一弯引号为直引号、书名样式方括号为方括号、长短排版破折号/数学负号为 `-`。
   大小写不折叠；不删标点全集；字母、数字、否定文字、`%`、小数点、正负号、斜线、比较运算符均保留。
2. 去除明确的 Markdown 表格分隔行（每格仅至少三横线及可选对齐冒号），去掉有首尾 `|` 的表格行分隔管道；
   转义管道保留为文字。不删除普通句中的 `|`、数字符号或横线。
3. 去除白名单 HTML 排版标签（table/thead/tbody/tfoot/tr/td/th/p/div/span/br/b/strong/i/em/u）；
   保留其文本，解码 HTML 字符实体。未知标签不删；`<`/`>` 数学表达式不作为标签吞掉。
4. 长度指上述规范化后的 Unicode 码点数；两方向包含的较短串至少 8。小于 8 的 RAW 信号块始终不链接，
   不能借同位置或相邻上下文补回。阈值不是 token 数，也不是原文本字节数。

格式处理对 RAW/复制块相同，测试以两类以上合成材料覆盖。此函数仅方法候选使用，不能进入引文回验。

## 3. 连续定位、位置与歧义

原始三元组仍经 `material_pages` 固定修订/SHA 校验，按现行 `SegmentedSource` 得到信号块。保存全份 RAW
的定位单元以核唯一性：PDF 每页、Office 每个 OfficeBlock（其 offset/locator 由 OfficePageText 校验）。
不跨页或 OfficeBlock 拼接。唯一性范围是该固定修订全部 RAW 单元，含未记为方法信号的文字。

每个已引用复制块单独与每个记录信号块比较：

- **完整包含**：规范化 RAW 块在复制块内，或复制块在 RAW 块内。取较短串作为匹配文本；该文本在全部
  RAW 定位单元中只出现一次（同一位置内重复也算歧义）。满足则只链接这个信号块。
- **连续部分重叠**：完整包含不成立时，仅 Office 信号块允许；RAW 的后缀与复制块的前缀、或 RAW 前缀与
  复制块后缀，取最长连续交集，至少 40 字。交集全在该 RAW 信号块所属的一个已校验 OfficeBlock 内，且在
  全份 RAW 定位单元中唯一。只链接实际满足条件的信号块，不扩到同位置其他块或整页。
- 不接受两边都有未匹配前后文的内部公共短语；不合并多个短匹配凑 40 字。两串相同上下文中仅数字/否定/
  `%`/符号被替换时，不以未变的前半段绕过失败；最长交集如有多处位置解释，拒绝而不挑最有利的一处。
- PDF 仍仅双向包含，没有部分重叠扩展。完整包含现在也拒绝规范化多位置歧义。

无匹配仍报告 `NO_RECORDED_BLOCKS`；已有复制未就绪/未映射、记录失效代码不变。候选去重与块阅读顺序不变。
不能从候选链接推断整个块都被复制块引用、模型用过所有事实或 Claim 语义正确；后续仍只从 RAW 取值并逐项回验。

## 4. 两栏召回（只计数，不输出正文或私有标识）

`CandidateRun.report`/现有 `methods candidates` 标准输出新增 `recall`：

- `eligible`: `{total, covered, ratio}`，分母 = 登记表当前 active 用途记录的全部 ≥8 字信号块，
  按 `(原始三元组, block_id)` 去重；分子 = 最终候选链接的去重集合与分母相交。不因未映射/未引用而缩小分母。
- `short`: `{total, covered}`，小于 8 字单列，covered 固定 0；不进入门槛。
- `gate`: `{minimum: 0.5, passed}`，只用 eligible 比例，零分母 ratio 为 null、passed 为 false。
  50% 是 #536/#539 的候选召回继续条件，不是 pack 准入或执行 values 的授权，也不会触发任何后续命令。
- 所有 active 来源只读一次并缓存；失效记录不读不计。已记录块在固定修订中找不到则整次 typed
  `RECORDED_BLOCKS_MISSING` 停止，不能静默缩小分母。来源读取/SHA 错误沿原错误停止。

`method-candidates.v1` 结构不变。报告新增键不要求迁移既有文件；报告本身不作为发布依据。

## 6. RED 反例与正控

- Markdown 表格/HTML 格式、NFKC/引号；保留百分号/小数/比较符的完整匹配；PDF 原完整包含正控。
- Office 前缀/后缀两方向重叠，40 字通过/39 字失败，只链接命中块；跨复制块、跨 RAW 页或 OfficeBlock
  拼接失败，PDF 部分重叠失败，内部公共短语不拼接；数字/否定/百分号/小数/正负号/比较符变化拒绝。
- 规范化后在另一页、另一 Office 位置、未登记信号块、同单元第二处出现均拒绝；合法单位置正控。
- 7/8 字边界；重复页引用不重复计数；未引用/未复制信号块仍计分母；短块/失效记录/零分母不冒充通过。
- 原始来源修订/SHA 和 discovery/RAW 隔离沿用；候选输出不含正文；宽松定位得到的块在后续取值仍生成 RAW
  精确引文，修改逐字关键句仍被原 `PHRASE_NOT_VERBATIM` 丢弃（不改原校验器）。
