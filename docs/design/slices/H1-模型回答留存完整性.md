- 分支：`slice/h1`。本片 Spec 与新增 RED 由 Owner 2026-11-02 明确授权 Codex 编写，各自独立提交后冻结。

## 1. 目标与边界

产品编译回放、概念页和独立审核只复用能与成功台账逐请求核对的回答。校验的是保存来源及运行身份，
不是语义真值、模型质量或发布准入。保留三条路径原有领域解析、评分、材料/卡片/协议身份与路由。

共性文件检查和台账背书从 methods 下沉到 models。models 不依赖任何 compiler；methods 继续拥有其
平面目录、stage 绑定、手工离线接口和方法级失败策略。不能复制第二套文件安全实现。
不改变发布合同、平台、模型阶段配置、重试次数、准入、字段卡、Golden、原评委规则或业务材料。

## 2. 留存与信任

1. 复用时同时检查：当前请求按真实适配器 `request_sha256` 得到的 HTTP body SHA、保存回答原始 UTF-8
   字节 SHA、stage/model/policy 及该成功记录的实际 served model（无返回版本时使用配置模型）。
   同一 run 的服务版本漂移仍拒绝。不能仅检查模型字符串或自带摘要。
2. 概念/审核的缓存键覆盖完整请求与语义 stage 设置（含 temperature、max_tokens、thinking、
   reasoning_effort、response_format 等）；timeout/max_attempts/api_key_env 是操作项，不使合法回答失效。
   policy、材料、题目或语义配置变化视为新请求；旧答案仍需完整性成立，才允许发送新请求。
3. 每份留存元数据关联一次真实台账记录，包含请求/回答摘要及发送配置，不公开正文。
   接受标记仅在领域解析成功后写入；产品按原调用顺序保留，包括重复相同请求的两次回答。
   未接受的已知回答只用于诊断；不存在以旧回答补造成功台账的迁移。
4. 留存通过 OpenAICompatibleCompletion 的 keep 能力，在回执记账之后、返回或抛出截断之前保存正文。
   允许适配器公开安装留存回调和读取配置，供运行级工厂建立后接入；不新增重试 Owner。
   截断停止整次运行，原文留存但不能成为接受答案。服务漂移先拒绝，不留漂移正文。
5. 开始时检查整个本次 run 的保存集合，再发送；恢复只使用已核验回答。台账中已成功但正文/元数据
   未完整落盘、发送预约没有回执等不完整状态拒绝恢复发送，需人工核对并使用新目录；不盲目补发。
   预算仍按每次实际 transport 尝试预先持久预约。额度耗尽本身可先拒绝新工作。
6. 校验失败不产生新 output/scores/concepts/candidate，不提交平台；既有审核分数和概念文件按原协议
   撤为 `.previous`，不是新的有效结果。未变配置的完整回答零发送复用，重复执行不覆盖原文。

## 3. 文件边界

- 所有目标运行目录、回答子目录及其祖先必须在 Git 工作树外（`.git` 文件/目录均算）；路径组成
  不允许符号链接。递归目录检查只 lstat，不打开未知条目；文件必须是普通文件，拒绝 FIFO/socket/device。
- 保存文件统一安全读取：先 lstat 普通文件，`O_RDONLY|O_NOFOLLOW|O_NONBLOCK` 打开，再 fstat
  普通文件且 dev/ino 与 lstat 相同。链接替换/FIFO 替换不等待、不跟随；异常固定 typed code，不泄漏路径或正文。
- 检查在任何发送及运行写入前执行，并在持锁后/读取时复核；独占锁与只新建写入保持。
  不承诺抵御拥有同一用户权限、持续改写整个目录与台账的恶意进程；已知替换窗口仍必须检查。
- 方法目录保留仅 `raw/` 子目录的布局约束，产品允许产品/responses/attempt 层级，概念与审核保留原布局。

## 4. 历史与离线兼容

- 旧成功记录缺 response_sha256 或保存件缺完整留存元数据：拒绝作为可信回答复用，不补写摘要并宣称可信。
  运维保留旧目录用于只读诊断，另起目录重新运行需原有预算授权；本片不执行迁移或真实重跑。
- 仅旧台账、没有待复用回答的目录可以保留其历史累计消费；不能把已耗预算清零。未知预约不能恢复发送。
- 产品 compile_products 的纯 CompletionPort 注入仍是离线评估接口，可保存/顺序回放合成答案，但须显式
  标记为 offline 来源；不能与真实台账源混用或获得真实来源身份。评估用 candidate.json 不是平台 CandidateBundle。
  离线来源的 CompileOutput 不能经 claims_from 转成可发布 Claim。直接调用纯编译器的既有测试接口不扩审。
- 本片不为旧 output 或旧分数补造可信证明；需要新模型调用的迁移不在授权内。SK-2c 既有持久格式及
  SavedResponses 手工离线/live 拒绝边界保持，改为复用公共安全读取与背书核验。
