# S12c-12a 字段规则同源

状态：冻结；Refs #552 第1部分；实现 Codex，审核 Claude。

## 1. 目标与边界

字段卡是字段语义唯一权威，profile、选段示例不得给出相反要求。编译两步与 RV7
使用同一份版本化落位规则、字段卡和 S12c-7 来源优先规则。材料角色来自实际编译的
固定材料身份，不由评委按文件名另猜。只统一请求与规则，不声称模型一定遵守。

每条事实在一个 pack 只归一个字段：有专门字段归专门字段，没有才归最接近的现有
字段，不丢弃。选择依据段落与写入事实分开：混合段可为多个字段提供依据，各字段
只写归属自己的事实。完整 pack 字段集合随字段定义传递，不用当前批次冒充完整
pack；没有完整集合的临时调用明确未知，不能从空集合推断专门字段不存在。

同一事项条款已有规定时，说明书不同数值、起算点、比例和新增例外不写入 value；
条款未涉及的事项仍可用说明书。保留 S12c-7 原文。reviewed_value 不覆盖该规则。

## 2. 数据裁定

字段卡版本 `draft-2026-11-05a`。只改以下明确边界：

1. `sum_assured_range` 只收明确数值的上下限、范围、单位及对应适用条件。只有双方
   约定、保单载明或引用监管限额而没有数值，为 unknown；不能补造数字。profile
   删除“金额约定方式”及“无数字仍保留规则”的相反指令；三个非数值 present 示例
   改为 unknown、值空，保留示例身份与材料未提供数值的理由。
2. `benefit_interaction_rules` 示例只保留 includes 中给付引起的累计/互斥/扣减/先后及
   给付后责任状态；删自然到期、免责退还、无具体给付关系的主险终止。自身等待期
   退费归等待期；附加险给付事件影响本合同的关系按 includes 保留。
3. 新 `reimbursable_expense_scope` 卡：定义为可报销的费用类别与范围条件；includes
   逐项费用清单、合理且必要/实际发生、社保目录、医院等级/科室、地域及适用责任或
   计划。excludes 免赔、给付比例、金额限额（分别归相应专门字段；缺专门字段才按
   通用落位规则）。unknown：未说明费用类别或范围条件；明确无可报销费用才 absent。
   profile 同步，去掉扣除额/其他计算限制等越界指令。
4. 新 `outpatient_inpatient_scope` 卡：门诊/住院类别及条件；pack 无专门字段时承接
   门诊住院分项限额；有专门字段则归专门字段，不重复。费用类别及范围条件归上述
   新卡。不得由“限额”推断一项医疗责任实际存在。
5. `surrender_and_cancellation_terms` 退还什么、何时及如何申请归本字段；退款/现金
   价值怎么算，有 `cash_value_rules` 归后者，没有才由退保字段承接。
   `cash_value_rules` 不再重复“退保退还现金价值”这一结果事实，计算/定义仍保留。
6. 旧 S12c-11 的九个给付规则卡仍保留只针对该给付的不给付条件，但撤回“同时选入
   exclusions”；exclusions 不再重复已有专门给付字段的专属条件。无专门给付字段
   时才承接。这是新裁定替代旧双重落位，不更改伤残鉴定机构/申请材料的原分工。
7. `premium_payment_frequency` 消除 profile 与卡关于通用支付日释义的冲突：释义仅
   罗列月/季/半年/年，不证明本产品实际提供这些选项；有本产品明确适用约定才收。
   不在本 PR 放宽费率来源信任。

通用文案无产品 ID、样本标题或固定答案特判。示例纠正不是修改 Golden 或重标模型。

## 3. 请求和身份

`field_cards.json` 根部增加版本化通用规则；公开访问函数同时供 card_payload 和
VALUE_PROMPT 使用，移走原私有常量的单独来源，不留双份规则。card_payload 携带
通用规则与完整 available_fields（无法确定时 null）；两步相同，writing_rule
仍仅第二步。pack_definitions 取完整目录字段再按原方法筛选/编号。

RV7 原来已有 card_payload(examples=False)，继续使用；实际题目增加同源来源规则
及每份全文的实际角色。role 从已验证 compile output 的 material_roles 按
knowledge_id/attempt/SHA 精确匹配；无记录为 null，不猜测。角色随 material 和
既有 basis 绑定；字段规则/pack 集合由 field_digests 绑定，变动继续 INPUTS_CHANGED。
不改评委 verdict 标准、提示词文本或发布状态机。

所有 11 pack 的全局 cards identity 改变，旧 output 不复用。直接语义影响以上字段
及九个给付卡；profile 不改变字段 semantic_sha256。取值协议仍为 .4：提示词原
S12c-7 文本不变，本次身份由 cards_version 和请求内容负责。Claim 仍按现行 decision
顺序，不能把版本变化说成全部 UPGRADE。没有自动重编、发布、准入或解暂停。
