# S12c-9 串字段：剩余热点字段

> 状态：Spec（2026-10-29，Claude）。实现方 Claude，审核方 Codex（复杂档：字段卡与第二步请求内容，影响编译器身份）。
> Issue：#442（诊断）。真实调用：消融 DeepSeek ≤ 100、GPT-6 Astra xhigh ≤ 3 个会话；实现与测试为 0。

## 1. 问题

#428 与 #436 两轮评委批次中判为“属于其他字段”的 135 条（70 + 65）里，热点集中在少数字段（#442 §1）。
页级核对显示 122/135 的混入发生在本字段自己第一步选中的页上，再由第二步写进值（#442 §2，页级判定，未逐句绑定）。
卡片文本分两类（#442 §3）：

- **混入句与本字段内容同在一个长段落**（`coverage_responsibilities`、`coverage_summary`、`cash_value_rules`）：只能在
  **取值侧**排除。S12c-5（#425 R2）证明在选段侧收紧 coverage 卡会丢本字段证据（−7，p=0.016，已撤回）。
- **混入句是单独的短段**（`sum_assured_range`、`accident_definition_and_criteria`、`product_bundle_rules` 约一半）：
  可以在**选段侧**收窄。

## 2. 改动（卡片数据 `draft-2026-10-28a` → `draft-2026-10-29a`，加一处第二步请求内容）

### 2.1 写值规则 `writing_rule`（只到第二步）

字段卡新增可选键 `writing_rule`：说明写 value 时，同一个已选段落里哪些内容不写入。`card_payload(examples=False)`
（第二步）带上它；第一步的请求不带，所以第一步的选段不受影响。

| 字段 | writing_rule 要点 | 对应 #442 |
|---|---|---|
| `coverage_responsibilities` | 给付段落中“若……我们不承担（不给付）……”的免责句不写入（归 `exclusions`），同段给付规则照常写入；分红型只写“本合同为分红保险合同，有权参与红利分配”一项，分配方案等归 `dividend_rules` | A、F |
| `coverage_summary` | 同上免责句规则；红利的分配与领取不写入 | A |
| `benefit_interaction_rules` | 只写给付之间的关系与给付事件引起的终止；免责、等待期退费与终止、退保解除、各责任的给付条件与金额即使同段也不写入 | A |
| `cash_value_rules` | 贷款、垫交只写“以现金价值为限”，减额交清只写“以现金价值作为交清保费”；比例、利率、期限、计息与交清后金额公式不写入 | C |

这些都是原卡 excludes 已经划给其他字段的内容（`exclusions`、`dividend_rules`、`policy_loan_rules`、`policyholder_rights`
等），本片不改字段范围，只把“同段不写入”说清楚。`exclusions` 的 includes 补上“保险责任条文中夹带的免责句”，让这些事实
在责任免除字段有落点。

### 2.2 选段侧（短段）

- **B `product_bundle_rules`**：字段范围不变（与 Golden 一致：附加险保费随主险支付（#443）、附加险须一同办理减额交清
  （1824、1826、1828、1830、1847H 的 Golden 与 1837 示例都在本字段））。includes 写全组合关系；excludes 新增三类
  “只是提到主险”的条款：主险终止则本合同终止、生效日与主险相同、复效、续保条件中的主险情形、适用主险条款的事项（不入本字段）；
  贷款与垫交所称“保险合同”包括附加险等权益适用范围（`policyholder_rights` / `policy_loan_rules`）；投保资格与免等待期
  （`insured_eligibility` / `waiting_period`）。bad 补上“主险终止则本合同终止”这类反例。1806 示例的 pitfalls 中
  “保费随主险支付不是组合销售规则”与 #443 的 Owner 裁定冲突，改为只指“适用主险条款目录、主险终止导致本合同终止”。
- **D `sum_assured_range`**：includes 注明只选写有数值、份数或上限规则的段落；unknown_rule 写明只有“约定并载明 / 变更后
  适用 / 按第几条计算”等程序性条文时为 unknown。
- **E `accident_definition_and_criteria`**：按“免责理由”划界——只选因“不是意外伤害”而免责的条目（疾病、妊娠流产分娩、
  药物过敏、精神和行为障碍、故意自伤或自杀、猝死）；因被保险人行为或所处风险而免责的条目（故意犯罪或抗拒刑事强制措施、
  酒驾、无证驾驶、战争、核辐射、高风险运动、医疗行为）归 `exclusions`。

`premium_payment_frequency`（S12c-5 已改）继续观察，不动。

### 2.3 不做

- 不改提示词、协议版本、引擎与选段算法；不加确定性的语义过滤。
- 不改其他字段的范围。Golden 中 `cash_value_rules` 含贷款比例的标注（如 1824、1826）与原卡 excludes 本已不一致，
  留给 S12e 关键事实审计（#432），本片不改 Golden。
