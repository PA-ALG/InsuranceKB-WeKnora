## 请求合同与范围

沿用 S12c-12a。两步编译和 RV7 从字段卡根规则取得同一版本化规则、同一完整 pack 字段集合；问题中的选段示例只用于第一步。更新 field_cards.json 与存在相关指示的 extraction_profiles.json。取值协议、提示词正文、来源信任与运行时代码保持现行合同。选择混合段作为证据与把段内全部事实写进同一字段分别判定。

| 字段 | 内容与反例 | 直接影响 pack |
|---|---|---|
| coverage_and_renewal_terms | 非保证续保但期满可重新申请为 present，记方式、审核条件和保障期限。原文明确不能续保且无重新申请安排才 absent_explicitly，附原文；沉默为 unknown。保证续保、停售已有专用字段时分别归专用字段，没有时主字段可收相关事实。 | 医疗、意外医疗、意外、重疾、失能收入损失 |
| coverage_responsibilities、coverage_summary | 第一张逐项保留名称、触发、给付基准与限定责任本身的关键时限；第二张名称、每项一句核心给付及责任间关系。专门字段所收的等待期、免赔、分场景比例、申请时效、免责不作为汇总的完整性要求。基准本身可以是比例，责任触发时限不是申请时效。既有留出例只压缩已有事实，不引入材料或新标注。 | 全11类 |
| eligible_occupation_classes | 只有条款、说明书或投保规则明确给出允许/拒保类别才按原文记载；明确不限职业也属于允许范围。仅有费率行或差别定价，记 unknown。禁推放在 unknown_rule/bad。 | 全11类 |
| disease_definitions_and_criteria、covered_critical_specified_diseases | 释义年龄限制和释义中明确解除总免责的疾病例外，释义字段必写；只有缩小保障范围的限制可以在名单重复，缺少此重复不是遗漏。限制本身写在名单时，名单必写。列名不照抄医学定义。 | 重疾、护理、失能收入损失 |
| exclusions | 总免责条文本身但书必写；病种释义中的例外归释义字段，总免责可附一般阅读提示。 | 全11类 |
| multiple_benefit_payment_rules | 新专卡。明确仅给付一次为 absent_explicitly 并引原句；沉默为 unknown；明确多次给付才 present。给付后终止归 benefit_interaction_rules，不能仅凭终止反推次数。后者已有该规则。 | 重疾 |
| 根规则 | 无专卡时只有定义本来覆盖主题的字段才承接；否则记目录缺口。受益权指定、变更、遗产给付不是理赔申请资料；作为遗产申请时的继承权文件属于申请资料。汇总的最小事实、名单可重复的缩限及免责的一般提示是上述裁定中的例外。 | 全11类，包括无专卡字段 |

全11类为医疗、意外医疗、意外、重疾、定期寿险、终身寿险、两全、年金、护理、补充养老、失能收入损失。第7项另片盘点：前四类及护理、失能合计6类需补 beneficiary_rules，另5类已有。此片不改 pack 目录。
全局卡版本从 draft-2026-11-05a 到 draft-2026-11-06a。全部产品 pack 的旧卡版本输出失去复用资格。Claim 是否变更仍按原 decision 顺序处理。
