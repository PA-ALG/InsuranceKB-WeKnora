# S3f · 阅读排版：企业知识页面改成"读一篇整理好的文档"

> 状态：用户 2026-10-18 选定 A 方向（"不要增加太多额外的东西……希望人能更好的阅读"） ｜ 作者：Claude Code
> 实现方：Codex（前端）；审核方：Claude
> 参照：本机静态样稿 `/tmp/ui-mockups/a-product-1828.html`、`/tmp/ui-mockups/a-concept-cooling-off.html`（仓库外，用 epoch 28 的真实数据生成，只作视觉参照，不进入仓库）

## 1. 目标与边界

- 只改呈现：数据、路由、读取的 Release、引用定位、模型内容的标注规则都不变。人和 agent 读的是同一份发布内容。
- 不新增功能模块：不加关键信息卡、右侧目录。知识图谱另立切片（S3g），本片不涉及。
- 覆盖页面：产品页 `EnterpriseEntity`、字段 `EnterpriseField`/`OutlineList`、概念页 `EnterpriseConcept`、空间页与左侧导航 `EnterpriseSpace`/`EnterpriseNavigation`/`NavigationEntry`、出处抽屉中的来源说明。

## 2. 改动（数值取自样稿 A，可在 ±2px 内微调）

1. **去掉框**：分区不再有边框和卡片背景；分区标题 20px、加粗，下方一条细分隔线，上下留白约 32px/12px。字段之间不画横线，用 20px 左右的间距隔开。
2. **阅读宽度**：正文栏最大宽度约 46rem（每行约 40 个汉字），在内容区中居中或左对齐；正文 15px、行高 1.8。
3. **层次**：
   - 产品名 28px；
   - 标题下一行灰色小标签：险种（该产品 profile 的 `display_name`）、"发布版本 N"，替换原来单独一行的"发布版本 N"；
   - 字段名 13px、次要文字色，放在值的上方；值本身是最醒目的文字。
4. **出处**：
   - "出处 n" 改为灰底圆角小标签（12px），悬停或获得焦点时变为品牌色；
   - 每个仍是独立按钮，打开同一条证据；可读文字仍是"出处 n"；位置仍在字段底行右侧（#214）。
5. **模型补充**：保留"左侧 3px 色条 + 浅色底 + '模型补充'文字标签"三者同时出现；概念页的模型说明区同理，标签沿用现有文案。
6. **概念页**：
   - 定义作为导语段，17px；
   - 对照表：表头浅灰底，行间细线，可横向滚动的外层不加卡片边框；
   - 其余结构不变（S3e-2）。
7. **左侧导航**：
   - 去掉卡片边框，改用浅灰侧栏底色；
   - 领域页签改为分段控件样式；
   - 分组标题后的条目数靠右；
   - 当前条目高亮保持。
8. **深色模式**：所有颜色继续使用 TDesign 变量，深色模式下自动适配。

## 3. 验收

- **RED**（Claude 编写，受保护）：`frontend/src/enterprise/readingLayout.spec.ts`：
  1. 产品页标题下的 `[data-entity-meta]` 显示险种名与"发布版本 N"；
  2. 每个出处按钮带 `ek-source-chip` 类，文字仍是"出处 n"，点击仍打开对应证据；
  3. 模型补充的字段带 `ek-field--generated` 类，并显示"模型补充"标签。
- 现有页面测试全部保持通过（S3d、S3e-2 的结构与交互断言不变）。
- **视觉验收**：实现方提供产品页与概念页在 1440px、深浅两种模式下的截图，存放在仓库外，PR 里只写位置；用户在浏览器里确认。
