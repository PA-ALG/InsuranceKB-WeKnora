# S6d-2 · 延伸阅读导航与企业知识报错提示

> 状态：Claude 2026-10-20 提出（S6d 审核的非阻断建议；用户在对话中选了旧 G3 受管库后看到原始错误码）｜ 作者：Claude Code
> 实现方：Codex（前端）｜ 审核方：Claude ｜ 真实模型调用：0

## 1. 延伸阅读导航跟随当前页面

- `EnterpriseNavigation` 增加可选属性 `wikiPageKey`（形如 `concept/xxx`），原样传给对应产品的 `NavigationEntry`。
- `EnterpriseWikiPage` 把当前页面的 `${pageType}/${pageSlug}` 作为 `wikiPageKey` 传给导航（与 `entityId` 一起）。
- `NavigationEntry` 在 `wikiPageKey` 属于本产品的某个页面时：
  - "延伸阅读（模型整理）"分组带 `open`；
  - 对应页面的链接带 `aria-current="page"`。
- 没有 `wikiPageKey`（产品页、概念页等）时行为不变：分组默认折叠，没有链接带 `aria-current`。
- 用户手动折叠或展开分组后，在同一页面内不被覆盖；切换到另一个页面时按新页面重新决定。

## 2. 企业知识报错在对话中显示为提示

新增 `frontend/src/enterprise/chatErrors.ts`：

```ts
export function enterpriseChatError(raw: string, t: (key: string) => string): string | null
```

- **识别规则**：`raw` 以下列错误码开头，且错误码后面紧跟 `:` 或字符串结束，返回对应文案；其他情况返回 `null`。前缀不同、错误码后面还有其他字符（如 `RELEASE_MANAGED_KBX`）、或错误码不在开头，都返回 `null`。

| 错误码 | zh-CN 文案 |
|---|---|
| `RELEASE_MANAGED_KB` | 这个知识库由发布版本管理，不能直接检索。请在企业知识中选择对应 Space 的原始材料库或 Wiki 库提问，或改用智能推理模式。 |
| `MANAGED_KB_CLASSIFICATION_UNAVAILABLE` | 暂时无法确认这个知识库是否由发布版本管理，已停止回答，请稍后重试。 |
| `RELEASE_SOURCES_UNAVAILABLE` | 当前发布版本固定的原始材料暂时不可检索，请稍后重试或改选 Wiki 库。 |
| `RELEASE_NOT_FOUND` | 这个企业知识 Space 还没有发布版本，暂时不能问答。 |

- 文案放在语言包 `enterpriseKnowledge.chatErrors.*`，5 种语言同步。
- **接入点**：对话流把服务端错误字符串写进消息并弹出提示的位置。按调研是 `frontend/src/composables/useChatStreamHandler.ts` 约 892–901 行与 `frontend/src/views/chat/index.vue` 约 931 行，以实际代码为准。两处改为先调用 `enterpriseChatError`，有结果就显示提示文案，否则保持原样显示。
  - 这两个上游文件新增登记；
  - 原始错误串仍写入日志或控制台，便于排查。
- **不做**：在知识库选择器中隐藏或置灰旧受管库。需要按知识库查询托管状态，代价与收益不成比例；旧 G3 测试库是否归档由用户决定。
