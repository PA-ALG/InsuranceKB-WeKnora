# S3f-2 · 空间首页与导航：首页做"目录"，导航做"紧凑清单"

> 状态：用户 2026-10-18 认可样稿（"如果整体可以，先这样吧"） ｜ 作者：Claude Code
> 样稿：本机 `/tmp/ui-mockups/home.html`（仓库外，用 epoch 29 的真实数据生成，只作视觉参照）
> 业界参照（调研结论）：首页只做导向、以搜索为主入口（GitBook、Atlan）；保险产品列表一行一款、字段统一（慧择）；侧栏单行、紧凑、隐藏空分组、当前项高亮（Carbon、Primer、Cloudscape、NN/g）
> 拆分：S3f-2a 导航数据（Harness，Claude 实现）· S3f-2b 首页与导航页面（前端，Codex 实现，Claude 审核）

## 1. 目标

- 空间首页不再出现内部编号，也不再大片留白，打开就能看到"这里有什么、怎么找"。
- 左侧导航改为紧凑清单，长名称不换行，不再列"N 项"。
- 不新增模型调用，不改发布内容与引用规则；人和 agent 读的仍是同一个发布版本。

## 2. 设计

### 2.1 S3f-2a 导航数据（Harness）

`NavigationProfile` 增加两个可省略的字段，写入 `catalog/navigation.json`，随发布带出（旧 Release 不受影响）。`display_name` 可省略或为 null；`overview_fields` 可省略（缺省为空列表），不接受 null：

- `display_name`：空间的显示名，例如"保险产品知识库"；
- `overview_fields`：首页速览表的列，按顺序列出字段键，例如 `["entry_age_range", "coverage_period", "waiting_period", "cooling_off_period"]`。

两者都是数据，由 Harness 维护；前端不写死字段键与名称。导出合同 `navigation_profile.schema.json`。

### 2.2 S3f-2b 首页（`EnterpriseSpace.vue`）

1. **标题区**：
   - H1 用导航成员的 `display_name`，没有时用"企业知识"；
   - 标题旁一个灰色小标签"版本 N"；
   - 下面一行次要文字："X 款产品 · Y 个跨产品概念 · 每项内容附原文出处"，数字由 Release 计算；
   - 内部的 Space 编号只出现在版本标签的悬停提示里，不作标题。
2. **搜索框**：
   - 一个输入框，同时筛选产品和概念（在当前 Release 内按名称或标题做子串匹配，不请求服务器）；
   - 下方 6 个常用概念的文字标签，取被最多产品陈述的概念，点击即跳到概念页。
3. **产品速览表**：
   - 按导航分组的顺序分组，组标题带数量，空组不显示；
   - 列为"产品"加上 `overview_fields` 中各字段，列名取 profile 的字段标题；
   - 单元格显示"短值"，规则对所有字段一致、不按字段特判：
     - Claim 为 `absent_explicitly` 时显示"无"；为 `unknown` 或没有 Claim 时显示灰色"—"；
     - 为 `present` 时，取值第一句（到第一个"，。；;"为止，并去掉开头的"1. "这类序号）中如果只有一个"数字 + 单位"（日、天、个月、月、年、周岁、岁、%、元、万元、次、倍），就只显示这一项，例如"20日"；否则显示第一句，超过 24 字截断并加"…"；
     - 悬停提示显示完整原值。
   - 整行可点，进入该产品页，带 `?release=` 固定版本。
4. **常用概念**：
   - 一行 10 个文字链接，按陈述产品数从多到少排列，数量相同时按 profile 字段顺序；
   - 末尾"全部 N 个 →"，切换到导航的"概念"页签。
5. **样式**：
   - 只用一个主色（链接、选中、焦点），其余为灰阶；不用阴影卡片，不用彩色图标；间距按 8px 网格；
   - 内容区最大宽度约 1040px，速览表可以比产品页正文宽。

### 2.3 S3f-2b 左侧导航（`EnterpriseNavigation.vue`、`NavigationEntry.vue`）

- 宽 248px，浅灰底，右侧一条细分隔线，不再有外框；吸顶，单独滚动。
- 顶部是"产品｜概念"切换和一个筛选框。
- 险种作可折叠的组标题，右侧是浅灰小字计数；空组不显示；当前条目所在的组自动展开。
- 每个产品只占一行（约 32px）：长名称截断，用 `title` 显示全名；不再显示"N 项"第二行。
- 当前条目用浅主色底加主色文字。
- 原有的展开字段列表（`NavigationEntry` 的字段子列表）保留在当前产品下，样式与本节一致。

## 3. 验收

- **S3f-2a**（RED，Claude）：合同接受并导出两个新字段；`navigation.json` 给出 `display_name` 与 `overview_fields`，字段键都是目录中产品类 pack 的字段。
- **S3f-2b**（RED，Claude，`frontend/src/enterprise/spaceHome.spec.ts`）：
  - 标题、版本标签、计数行；没有 `display_name` 时退回"企业知识"；
  - 速览表的分组、列与短值规则（单个数字单位、截断、无、—、悬停原值），以及整行带 `release` 跳转；
  - 搜索筛选产品与概念；
  - 常用概念的排序与"全部 N 个"；
  - 导航单行、无"N 项"、`title` 为全名、空组不显示；
  - 原有页面测试保持通过。
- 视觉验收：实现方附 1440px 浅色与深色截图（存放在仓库外）；用户在浏览器里确认。
