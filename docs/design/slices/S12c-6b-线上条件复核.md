## 1. 问题

S12c-6（#435）的消融在**不带 carry** 的条件下进行（复评 r2 track A），双次选段使"遗漏关键内容"消除 16、新增 1。
生产重编带 S12c-4 carry（把已审核的线上证据段交给第二步）。#436 线上一轮（带 carry、双次选段）中，评委"遗漏关键内容"
占比从 #428 的 14.8% 升到 18.7%（重疾险 12% → 30%）。两轮评审的点集不同，不是配对结论，需要在线上条件下复核。

## 2. 零调用分析

- **两轮配对**：两轮都评审过的 233 个字段中，approve→遗漏 17、遗漏→approve 9；遗漏→遗漏 19。#436 的"遗漏"理由几乎都是
  "新值遗漏线上已有的……"：新值相对已发布值丢了事实。
- **重放 #436 的真实请求**：以 #436 的代码（`353188fbe`）、同一 carry 来源（epoch 103 `rel_22ef7b81…`）和保存的模型回复离线重放
  全部 17 款产品；请求指纹全部吻合，输出与线上输出逐字段一致。据此得到每个字段第二步实际拿到的段落（第一次抽样主选段、carry、
  第二次抽样补段）。
- **53 条"遗漏关键内容"分类**（**页级启发式**：解析评委理由引用的页，只要第二步输入中有其中任一页的任意段落即计入第一行；没有逐条绑定"缺失事实 → 确切段落 → 实际输入"）：

| 类别 | 条数 |
|---|---|
| 第二步输入中有评委引用页的段落（主选段 / carry / 补段） | 52 |
| 其中引用页段落只来自第二次抽样补段 | 0 |
| 第二步输入中没有评委引用页的任何段落 | 1 |

  重疾险 9 条都属于第一行（页级）。限制：
  - 页级覆盖不等于缺失的那条事实所在段落已送入，也不等于旧值每个事实都有对应引文；评委的遗漏判定是单模型代理判定，不是独立真值。
  - carry 只接受可完整解析、材料身份匹配的 present Claim：非法 locator 或任一材料失配时整条 Claim 不 carry；引文定位失败/歧义、第一步非 present 时也不传入。`used_segments` 无有效项时会保留全部补充证据，所以不能用输出 evidence 反证逐段实际使用。
  - `sc-a27860e39d/coverage_summary` 是新增字段（无旧线上值），不适用"carry 交出旧值证据"的推论。

  结论：52 条存在引用页级输入，**支持优先调查第二步写值**，但未完成逐事实归因，不能据此排除第一步漏选。

  记法：`+a/−b` 表示前一臂在该类上多 a 个、少 b 个字段（"遗漏""其他字段""错误"多即更差）。

- 读法：双次抽样让第二步拿到更多段落（证据完整略多），取值没有看到改进；各配对差异与同臂重复的噪声同量级，任何一项都不显著。
- 限制：这是按既有拒绝（#436 判遗漏/串字段）与臂间差异筛选字段的单模型代理样本；六组配对共享同一批字段和输出，不能合并当独立重复；
  样本只有一款完整产品加一款半，统计能力很弱。不显著不等于没有收益。该对照用协议 `.1`，也不是对当前同时含 S12c-7 规则的 `.3` 的整体质量验证。

## 4. 决定

1. 生产 `SELECTION_DRAWS` 改回 1。这是**成本决定**：双次抽样使第一步调用翻倍（每款约多 2–3 次），而本轮线上条件下没有看到收益
   （不等于已证明无收益）。引擎的 `selection_draws` 参数与补段机制保留，供以后在新条件下再试；直接使用引擎仍为 1。
2. 值协议版本升为 `2026-10-29.3`，记录生产管线回到单次抽样（编译器身份如实反映管线）。按作者运维记录，#436 使用 `.1`，`.2` 尚未用于
   线上编译（本次没有做全局线上核查）。若下一轮线上重编所比较的批次没有经过 `.2` 的中间重编，那么这次升级不会比 `.2` 多出一次
   输出失复用；无论哪个版本，下一轮都是新身份。
3. 下一步优先调查第二步写值（例如重编时让第二步知道已审核的线上值、不得无故丢弃仍有原文依据的事实），另立切片，先做逐事实归因与消融。
