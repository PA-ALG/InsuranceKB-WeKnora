# 006 · 模板抽取 Fast Path 与表格结构识别

> [!CAUTION]
> **历史、不可执行、production-disabled。** 本 change 依赖的模板/路由是可迁移第一方资产，但还保留强模型润色入口；旧范围通过不等于 028 `TemplateVersion/Approval/provenance receipt` 或生产准入。027/028 与适用 admission 未通过前不得加载这些模板生成真实候选。

> 设计权威：docs/insurance-kb/11 §1（三层模板设计）、§2（解析升级链）。本提案是其 change 化，细化范围与验收。

## 为什么做

同构文档（同族说明书/费率表）用归纳出的模板做锚点抽取，可大幅降低 LLM 调用并定点提准；11 §1 已定原则：**模板是归纳出来的不是人写的，建不建由按族分数决定**。004 已交付族指纹与按族出分框架，本 change 交付模板机制本身。

## 做什么

1. **模板 schema 与注册**：`harness/src/insurance_harness/compiler/templates/` — 模板为 YAML 数据（family_id、字段→锚点：章节标题模式/表格列名/正则/页位置、few-shot 示例），版本化，与 schema 注册表同机制加载校验；
2. **模板归纳器**：输入 = 某族 ≥2 份文档 + 对应金标（字段→证据页/引文），输出模板草案 YAML + 归纳报告（每个锚点在族内的命中率）；强模型一次性调用（claude-session 或网关 judge 模型，可配）；**人工只审核草案**；
3. **运行时 fast path**：管道入口族识别 → 命中已发布模板 → 锚点定位 → 确定性抽取（正则/表格列）或单字段小调用 → 统一走既有校验链（回验/清洗/三态）；锚点未命中字段自动降级通用管道（004）；
4. **表格结构识别接入（PP-StructureV3）**：独立解析服务进程（08 选型，进程隔离），费率表/利益演示表 → markdown 表；解析质量检测不达标自动回退 pdfplumber 文本；模板锚点支持"表格列名"类型即依赖此项；**按 12-dayu-borrowings.md #1，表格结构化后数字类字段改为"列定位直取"（data_quality=table_parsed），LLM 不再抽原始数字**；
4b. **文档可喂性评分**（12 #4）：解析产物进管道前的确定性打分（表格列名合法/截断/乱码/超大 section），与 11 §2 升级链的质量检测合并实现，不达标进隔离区；
5. **验收路径**：选按族样本最多的一族（盛世金越系列说明书/费率表族，族内 ≥4 文档）建首个模板，对比 fast path vs 通用管道：字段分数不降、LLM 调用次数下降 ≥50%（该族内）。

## 不做什么

- 不做模板编辑 UI（workbench 后续）；不做全险种模板铺开（按族分数逐个立项）；图形图表 caption-first 通道（11 §3）另列（依赖 qwen-VL 通道打通，遗留清单补充项）。

## 依赖

004 合入；005 的按族错误归因数据（决定首个模板族的选择依据更充分，但不硬依赖）。
