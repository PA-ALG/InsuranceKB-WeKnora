# 025 合并前置弱值门槛 · 任务

> 依赖：007 主链 + 018/021 knowledge 域基线——**实现排在 021 之后（PR #9 合入）**；提案与规格即刻定稿。文件域：`knowledge/merge.py` + 迁移 0011。测试名引用条款号（G1~G6）。零真实模型调用。

## 任务（红绿；每条护栏必配 accept 侧/负测——024 gauntlet 教训：只测拒绝侧=半个护栏）

- [ ] T1 **informationScore 确定性判据**（G2）：纯函数（长度/具体性信号：数值·日期·百分比·单位·枚举计数/结构完整度），零模型、同输入同输出；单测含确定性断言 + 分数可解释。**accept 侧**：具体值 > 粗略值、等价改写同分（不误判强弱）。
- [ ] T2 **弱值门槛接入 007 K2 前置**（G1/G3/G4）：merge 在冲突/supersede 判定前插门槛。**拒绝侧**：明确更弱的同/低权威值 → 不开 conflict/不生 ReviewItem/不落 Claim。**accept 侧（关键负测）**：相等/不可比/缺基线/计算异常 → **不抑制**，照 007 走；**更高权威更粗略值 → 不抑制**（G4），照 K2 supersede。
- [ ] T3 **抑制审计事件表**（G5；迁移 **0011**）：append-only、闭合 Space，含两值/两分/原因/时间戳；双方言（sqlite/pg）；抑制即写事件——**无审计的丢弃测试断言为违规**。抑制计数按 Space/批次可查。
- [ ] T4 **informationScore 仅排序信号**（G6）：暴露为 008 W1.1 可选排序信号；**负测钉死**：不存在"信息量更高即 auto-supersede"路径（构造 informationScore 更高但权威不更高的新值，断言 published Claim 不被替换）。
- [ ] T5 **收尾**：validation-report（条款→测试名 + 抑制事件样例 + fail-safe 边界枚举）→ HANDOFF 更新 → 008 W1.1 抑制计数展示交接说明。

## 裁决记录（设计判断及依据）

1. **门槛是前置过滤，不是替换路径**（G1/G6）：007 权威序/裁决语义一字不改；门槛只在 K2 冲突判定**前**决定"这个更弱值值不值得开审"，绝不引入"信息量替换"后门——否则弱模型可用高信息量垃圾覆盖高权威事实。
2. **fail-safe 是第一约束**（G3）：借 024 gauntlet 教训——护栏误伤的代价（静默吞掉更优值 = 召回/质量回归）远高于漏拦的代价（多开一次审）。故只抑制**明确更弱**，相等/不可比/缺基线/异常一律 fail-open；每条门槛测试必配 accept 侧负测，防止门槛自身变成丢值路径。
3. **与权威序正交**（G4）：更高权威的更粗略值是合法修订（如条款订正说明书），门槛不得抑制；门槛只在"权威不占优"时才谈信息量——信息量永不凌驾权威。
4. **绝不静默**（G5）：任何抑制留 append-only 审计（可计数、可复盘、可在 008 展示），与 024 F6"拒绝原因可审计"同纪律；无审计的 drop 即违规。
5. **迁移 0011**：抑制事件独立表（append-only），不复用 change_sets/conflicts（语义不同：抑制=未开冲突的前置丢弃，不是冲突记录）；已在 README 占号。

约束：文件域仅 `knowledge/merge.py` + 迁移 + 只读查询；不改 007 权威/裁决语义；不碰 compiler/goldenset/adapters；informationScore 不参考金标；送审前过 21 号自测 gauntlet（含 accept 侧红队：构造"更优值被误抑制"负例）。
