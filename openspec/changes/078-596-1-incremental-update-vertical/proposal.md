# Change: Freeze the 596-1 incremental-update vertical

## Why

The MVP needs one deterministic proof that a new SourceRevision changes only
declared field scopes while preserving every unaffected fact. Existing 058 and
059 contracts provide the algorithms and custody boundary, but no 596-1-shaped
vertical proves their composition.

## What Changes

- Add one task-local synthetic 60-field scenario with exactly four affected
  fields and fifty-six unchanged fields.
- Freeze the exact field-to-action mapping and canonicalize equivalent input
  ordering before any fixture or receipt hash is computed.
- Pin the approved ordered 596-1 Schema60 authority by its task-local canonical
  hash, in addition to revalidating the caller's 052 catalog and resolutions.
- Require caller-provided 053/054/057 custody, baseline fact hashes, candidate
  facts, exact `FieldCandidateV1`/Evidence snapshots, and an independently
  verified explicit-absence chain for retraction; the runner replays public
  verification rather than minting those inputs.
- Compose the existing 052/053/054/057/058/059 public contracts to produce one
  `enrich`, `supersede`, `conflict`, and `retract` action.
- Emit only deterministic hashes and non-authoritative fixture receipts.

## Impact

- No production knowledge, Golden values, provider/model, persistence,
  WeKnora, Release, API, migration, or UI behavior changes.
- No upstream governance algorithm is copied or widened.
- No baseline fact, parsed artifact, extraction receipt, or Evidence receipt
  is self-generated by the public runner.
