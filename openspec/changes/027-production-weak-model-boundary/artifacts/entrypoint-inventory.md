  offline Golden module entrypoint.
- `harness/src/insurance_harness/knowledge/__init__.py` was checked item-by-item for
  state-advancing exports. The relevant importer, ChangeSet/Claim, review/conflict,
  source-lifecycle and release functions are listed above. They remain zero-model and
  enforce their own governance contracts; they must not acquire direct

- `harness/src/insurance_harness/live_env/__init__.py` exports nothing; the probe is
  still directly importable from `live_env.model_probe` and is not an admission
  authority.

## Freeze decision

The inventory freezes four disjoint classes: (1) code-owned production composition roots,
production CLI and sealed pipeline/factory paths that require the canonical verified/guarded
boundary and currently fail closed before any provider adapter; (2) library/transport
primitives that a sealed production root may call, but whose standalone raw-client use is
offline/non-production and carries no production authority; (3) explicit offline/goldenset/
replay/manual paths that the production CLI never selects as fallback; and (4) zero-model
product/knowledge paths that keep their existing governance and snapshot contracts. Tests
machine-enumerate the two production roots, their code-owned construction proof, the guarded
primitive chain, and the absence of those callable primitives from the compiler package
export surface.

The capability boundary does not attempt to defend against arbitrary same-process Python
code choosing to call an offline primitive and relabel its in-memory return value. Such a
call has no `VerifiedAdmission`, cannot issue a production receipt or enter the code-owned
production pipeline, and is not evidence of production progression. Future 028 production
orchestration must supply the sealed `GuardedModelClient` when it invokes these primitives.
Callers never pass permit, policy, issuer or guard. This 027 patch does not implement a
general artifact-provenance or promotion gate: whether an offline artifact may later be
imported is a separate downstream owner/adapter contract and is not claimed here. A probe,
transport call, offline judgement, Golden run or artifact content is not by itself a
`VerifiedAdmission` or `IssuedModelPermit`.
